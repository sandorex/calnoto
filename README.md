## calnoto
calnoto (CALendar NOte TOdo) is opinionated calendar + todo + notes app for my personal workflow, targets Windows, Linux and Android

**Pre-alpha software at the moment**

The goal is to use simplest formats possible
- [todo.txt](https://github.com/todotxt/todo.txt) for todos
- [icalendar.txt](https://github.com/sandorex/icalendar.txt) for calendar
- Plain text or Markdown for notes (not set in stone)
